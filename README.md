# Windows Classic Volume Tray
Get tired of the Windows 11 volume tray? Get Windows 9x style tray back!

![Demonstration](demo.gif)

A tiny native Windows tray application that shows a classic **vertical** volume
slider when the tray icon is clicked.

## Download
Go to [releases page](https://github.com/march1993/win-classic-volume-tray/releases)

## Build
Requires [Zig](https://ziglang.org/) 0.17.0 or newer.

```sh
zig build -Doptimize=ReleaseSmall
# or simply
make
```

The executable is written to `zig-out/bin/win-classic-volume-tray.exe`
(and copied next to the sources by `make`). The manifest and tray icon are
embedded as Win32 resources by `zig rc`, so the resulting file is
self-contained.

## Notes
- Uses only Win32 / Core Audio COM APIs; no third-party libraries.
- The vertical slider sends the volume straight to the current default render
  device.
- If the app is started very early (e.g. at logon before the audio service is
  ready), the audio endpoint and the tray icon are retried until they become
  available. The slider therefore always controls the real audio output.
- Switching the default output device at runtime is picked up the next time the
  popup is opened.
- The tray icon is re-registered automatically when Explorer restarts.
